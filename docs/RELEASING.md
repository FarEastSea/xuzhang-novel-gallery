# 发布维护规则

公开版本以根目录 `VERSION` 为准，前三段对齐 Biz Novel Studio，第四段标记本站独立更新。

```sh
# 对齐创作台版本，清零独立更新编号
npm run version:set -- 0.7.1
# 创作台未变时，依次生成 0.7.1.1、0.7.1.2 等
npm run version:next
```

命令同步更新 npm 元数据；四段公开版本映射为带构建元数据的合法 SemVer，以保证 npm 安装和构建正常。发布前执行测试、构建与 `npm run check:release`。

Git 标签必须为 `v<VERSION>`。镜像工作流检查标签与源码版本是否一致，并发布精确版本镜像，不使用会丢弃第四段编号的 SemVer 标签转换。`latest` 指向最近一次正式发布。

运行数据、凭据和原小说快照不得提交。仓库当前为私有，未声明开源许可证。
